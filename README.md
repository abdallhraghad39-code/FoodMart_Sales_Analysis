# FoodMart_Sales_Analysis
📊 FoodMart Sales & Customer Analysis Dashboard  

I’m excited to share my latest data analysis project using Excel & Power Pivot 💡  

🔹 In this project, I worked on building a complete Sales Dashboard and Customer Analysis Dashboard based on the FoodMart dataset.  

✨ What I did:  
- Cleaned and prepared the data using Power Query  
- Built a Star Schema Data Model (Fact & Dimension tables)  
- Created relationships between tables using Power Pivot  
- Developed multiple KPIs such as:  
  - Total Sales  
  - Total Orders  
  - Total Quantity  
  - Total Profit  
  - Growth Rate  
  - AVG Sales Per Customers 
  - AVG Sales Per Stores
  - Profit Margin 

- Designed interactive dashboards using Pivot Tables, Charts & Slicers  

📈 Key Insights:  
- Sales show a noticeable increase towards the end of the year  
- Certain regions like North West dominate in sales performance  
- Top products significantly contribute to overall revenue  
- Mid-income customers ($30K–$50K) represent a major sales segment  

💡 Business Recommendations:  
- Focus marketing efforts on high-performing regions  
- Boost promotions during low-sales periods  
- Target key customer segments with personalized offers  

🛠️ Tools Used:  
Excel | Power Query | Power Pivot | DAX
